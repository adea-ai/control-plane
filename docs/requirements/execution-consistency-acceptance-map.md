## Inspected starting points and limits

- `tests/m3-durable-execution.test.mjs` explicitly uses a mock runtime and a synthetic Agent HQ receiver. Its acceptance/replay and progress checks cannot establish real Agent HQ durable WorkspaceEvent application or native runtime billing.
- `apps/local-control-plane/src/direct-runtime-recovery.test.mjs` uses real file-backed SQLite and injected runtime objects. Its lost start/result response cases prove a direct-dispatch boundary, not the earlier public command commit/reply boundary or native host restart.
- `packages/context/src/provider.test.mjs` exposes focused no-provider, policy, cache, substitution and fake-profile checks. These are inspection leads for rows 11–15, not an all-profile execution certification.
- `packages/domain/src/project-state.test.mjs` exposes competing-writer and revision tests. Reconcile those assertions with both concrete persistence providers before claiming row 09.

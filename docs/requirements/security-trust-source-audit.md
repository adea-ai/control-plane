## Boundary notes

Agent HQ owns user/auth mapping, product metadata, WorkspaceEvents, Artifact product metadata, RuntimeNode registration, LocalProjectGrant cloud metadata, and E2E sync product state. Control Plane owns execution policy, durable execution records, provider-neutral definitions, and authoritative usage/eval records. Neither product reads the other's database. The synthetic runtime-node identity authority remains the standalone-profile identity source; a production external identity backend is an M12 gate.
